# app-audio-bridge —— 只分享一个桌面应用的声音

频道页「一起听 → **分享本机应用的声音**」直连使用：本工具用 Windows 内置的
**WASAPI 进程级音频回路**（免驱动、免管理员）按进程树采集指定应用的声音，
频道页直接拉流混入发送——**不经本地扬声器**（零重音）、无需浏览器选择器。

要求：Windows 10 20H1+ / Windows 11；Python 3.10+。

## 用法

```bash
cd helper/app-audio-bridge
python -m pip install -r requirements.txt   # 本机示例：D:\miniconda3\python.exe -m pip install -r requirements.txt
python server.py                            # 后台跑着即可（会自动打开 http://127.0.0.1:8790）
```

1. 让目标应用（音乐客户端 / 游戏）出声
2. 频道页 → 点「一起听」→ **分享本机应用的声音** → 列表选它（只列能发声的应用，播放中的排最前）——本地零重音，远端只有该应用的声音

本工具自带的页面（127.0.0.1:8790）只用于**试听确认**：选中应用后本页播放其声音（与源应用本地重音属正常现象），也可作为频道页直连不可用时的备用路径。

## 常见问题

- **频道页提示未检测到小工具**：确认 `python server.py` 在跑；频道页探测 127.0.0.1:8790~8794（端口被占自动顺延）。若频道页部署时 CSP 未放行这些地址（本仓库默认已放行），检查 `app/src/server.js` 的 connect-src。
- **应用列表为空**：先让目标应用出声（按活跃音频会话实时枚举），重新展开列表。
- **选中后远端没声**：同名多进程时频道页取「播放中」的会话；个别受保护进程（带反作弊的游戏）拒绝进程回路采集，见 [docs/share-app-audio.md](../../docs/share-app-audio.md) 备选方案。
- **端口说明**：默认 8790——浏览器把 8765 等端口列为受限端口（ERR_UNSAFE_PORT），不能用作服务端口。
